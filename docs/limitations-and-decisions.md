# Limitations & Decisions

These were researched against vendor docs on **2026-10-28**. Re-check them when a plan or vendor changes.

**How sure each row is:** ✅ means confirmed in current official docs. ⚠️ means the docs don't say or only third-party sources do, so it gets verified by experiment in the phase shown (see `PLAN.md`).

**Owner decisions (2026-10-28):**
- The app repo goes **public**, which gives free branch protection and unlimited Actions minutes.
- Watchtower runs **for free**: a GitHub Actions cron worker plus a dashboard on Render Free that sleeps when idle.
- Watchtower data lives in the **same Aiven service**, in its own database and user.
- An **Anthropic API key** is used for both diagnosis and fix runs.

## Key consequences
- **No webhooks anywhere in v1.** Render webhooks need Pro, Sentry integrations need Team, and a sleeping dashboard would drop them anyway. Everything is pulled by the worker ([ADR 0001](adr/0001-pull-based-ingestion.md)).
- **Detection latency is 15–30 minutes.** That's acceptable because v1 has no real-time alerts.
- **The Render API key is too powerful.** It's confined to the worker's Actions secrets until a scoped key is available ([ADR 0005](adr/0005-manual-rollback-v1.md)).
- **Free hours are budgeted:** about 500–550 h for the app plus a few hours for the dashboard, against 750 h ([ADR 0002](adr/0002-actions-worker-and-sleeping-dashboard.md)).

## When the API key is needed and what it costs
- **First needed:** at the start of phase 3, for diagnosis. It is reused in phase 4 for fix runs, as an app-repo secret.
- **Setup:** create a dedicated Claude Console workspace "watchtower" with a $20/month spend limit, and buy a small prepaid credit.
- **Expected spend:**
  - about $0.07 per diagnosis (Sonnet 5.5)
  - about $1–4 per fix run (Claude Code plus three reviewer agents)
  - under $15/month at roughly 10 incidents and 3 fixes
- **Detail:** see [ADR 0006](adr/0006-model-choice-and-cost-controls.md).
